# 재활감염 Quick Check (PWA)

치료 전 30초 감염관리 체크 · 재활치료 현장 참고용 도구.
안드로이드 · iOS · 태블릿 · PC에서 모두 반응형으로 동작하며, 홈 화면(바탕화면)에 앱처럼 설치할 수 있습니다.

## 폴더 구성
```
index.html          앱 본체 (단일 파일)
manifest.json        PWA 설치 정보 (아이콘, 앱 이름, 테마색 등)
service-worker.js     오프라인 캐싱용 서비스워커
favicon.ico           브라우저 탭 아이콘
icons/                홈 화면·설치용 아이콘 (16px~512px)
```
이 5개 항목을 그대로 GitHub 저장소 최상위(루트)에 올리면 됩니다. 서로 상대경로로 연결되어 있으므로 폴더 구조를 그대로 유지해야 합니다.

---

## 1) GitHub에 올려서 배포하기 (GitHub Pages)

계정/토큰 없이 웹 화면만으로 가능합니다.

1. [github.com](https://github.com) 로그인 → 우측 상단 **+** → **New repository**
2. 저장소 이름 입력 (예: `rehab-infection-check`) → Public 선택 → **Create repository**
3. 저장소 페이지에서 **Add file → Upload files** 클릭
4. 아래 5개를 그대로 드래그해서 업로드
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - `favicon.ico`
   - `icons` 폴더 전체 (폴더째로 끌어다 놓으면 `icons/icon-192.png` 형태로 경로가 유지됩니다)
5. 하단 **Commit changes** 클릭
6. 저장소 상단 **Settings → Pages** 이동
7. **Build and deployment → Source**를 **Deploy from a branch**로 두고, Branch를 `main` / `/(root)`로 선택 후 **Save**
8. 1~2분 후 같은 화면 상단에 다음과 같은 주소가 표시됩니다.
   ```
   https://<깃허브아이디>.github.io/<저장소이름>/
   ```
   이 주소가 최종 접속 주소이며, 스마트폰·태블릿·PC 어디서나 이 링크로 접속하면 됩니다.

> 참고: 저장소는 반드시 **Public**이어야 GitHub Pages 무료 배포가 가능합니다.

## 2) 각 기기에 앱처럼 설치하기

배포된 링크(`https://.../`)로 접속한 뒤 아래 방법으로 설치합니다.

### 안드로이드 (Chrome)
- 링크 접속 시 하단에 **"홈 화면에 앱으로 추가"** 배너가 자동으로 뜹니다 → 탭하면 설치 완료
- 배너가 안 보이면 Chrome 우측 상단 **⋮ 메뉴 → "앱 설치" / "홈 화면에 추가"**

### iPad / 안드로이드 태블릿
- 스마트폰과 동일한 방법 (Chrome은 배너, Safari는 아래 iOS 방법과 동일)

### iPhone / iPad (Safari)
- 링크 접속 시 하단에 **"홈 화면에 추가"** 안내 배너가 표시됩니다
- Safari 하단 **공유 버튼(⬆️) → "홈 화면에 추가" → 추가**
- ⚠️ iOS는 반드시 **Safari**로 접속해야 설치 배너/기능이 동작합니다 (카카오톡 인앱 브라우저 등에서는 미지원)

### PC (Windows / macOS, Chrome·Edge)
- 주소창 우측의 **설치 아이콘(⊕ 또는 모니터 모양)** 클릭 → **설치**
- 설치 후 데스크톱/시작 메뉴에 독립 앱 창으로 실행됩니다

설치된 앱은 서비스워커 덕분에 한 번 접속한 뒤에는 **오프라인에서도 실행**됩니다 (콘텐츠가 로컬에 데이터를 저장하지 않는 특성상, 갱신된 판단 로직 확인을 위해 가끔 온라인 상태에서 새로고침해 최신 버전을 받아오는 것을 권장합니다).

## 3) 반응형 동작 요약
- **스마트폰**: 기존 카드형 화면 그대로 유지 (세로 최적화)
- **태블릿(약 700px 이상)**: 카드 폭 확장, 선택 항목(치료 파트)이 한 줄 4열로 배치, 여백·글자 확대
- **PC(1024px 이상)**: 배경에 여백을 두고 앱이 카드 형태로 중앙에 표시, 버튼·항목에 마우스 hover 효과 적용
- iPhone 노치/하단 홈 인디케이터 영역은 safe-area 여백으로 자동 회피됩니다

## 4) 업데이트 방법
로직/문구를 수정하면 `index.html`의 `service-worker.js`에 정의된 `CACHE_NAME` 버전 문자열(`rehab-infection-check-v2.0`)을 올려주세요. 그래야 이미 설치된 기기에서도 오프라인 캐시가 새 내용으로 교체됩니다.
